# IMC Calculator

Calculadora de Índice de Massa Corporal (IMC) desenvolvida em Java.

O projeto tem como objetivo praticar conceitos de programação em Java, incluindo entrada e validação de dados, operações matemáticas, estruturas condicionais e organização do código.

## Funcionalidades

* Cálculo do IMC a partir do peso e da altura.
* Classificação do resultado do IMC.
* Interface para entrada dos dados.
* Exibição do resultado calculado.

## Melhorias a implementar

* [ ] Validar valores de peso e altura antes de realizar o cálculo.
* [ ] Permitir a utilização de vírgula (`,`) como separador decimal, além do ponto (`.`).
* [ ] Melhorar o tratamento de entradas vazias ou não numéricas.

## Tecnologias

* Java
* JavaFX

## Objetivo

Projeto desenvolvido para praticar e consolidar conhecimentos em Java e, posteriormente, aplicar melhorias relacionadas à validação de dados, tratamento de exceções e experiência do usuário.
